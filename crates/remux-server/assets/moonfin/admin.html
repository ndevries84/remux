Default client settings

Settings applied to every user as the lowest layer. Users' own settings override them. A setting you leave unset keeps the app's built-in default. The home rows (homeSections and homeRowOrder) are defaults that must be set together as a pair.

How settings combine

For each setting, Moonfin uses the first value it finds in this order:

  1. The device's own settings (the desktop, mobile or TV profile)
  2. The user's global settings
  3. These admin defaults
  4. The app's built-in defaults

Settings that Remux owns, listed below, are not part of this order. They come from each user's Remux settings.
